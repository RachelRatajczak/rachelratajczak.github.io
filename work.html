Polycystic Ovary Syndrome (PCOS) Diagnostic Prediction Model

Challenge

Polycystic ovary syndrome affects 6–13% of women of reproductive age, with an estimated 70% of cases remaining undiagnosed. Standard clinical workflows require reliable computational screening tools to improve early risk identification.

Solution

Evaluated and benchmarked multiple binary classification models using 1,000 patient records from Kaggle via 5-fold resampling. Key features analyzed included patient demographics (Age 18–45, BMI 18–35 kg/m²), menstrual irregularity, testosterone levels (20–100 ng/dL), and antral follicle count.

Impact

  • Identified Support Vector Machine with a radial basis function kernel (SVM-Radial) as the top performer
  • Achieved an exceptional mean accuracy of 97% and a Kappa value of 0.94
  • Benchmarked comprehensive models including Lasso, Ridge, Random Forest, and Gradient-Boosted Trees

Hadoop Multi-Node Cluster & Analytics Pipelines

Challenge

Modern datasets frequently exceed standard single-node memory limits, requiring fault-tolerant, distributed architectures capable of scaling across multiple networked nodes.

Solution

Architected and deployed a fully distributed Hadoop cluster from scratch across a 3-node Ubuntu virtual machine environment (1 Master node, 2 Worker nodes). Progressed from standalone configuration to a multi-node cluster, configuring SSH key-based authentication, HDFS, YARN resource management, and distributed data processing pipelines using Hadoop, Spark, Hive, and Pig.

Impact

  • Provisioned and networked a 3-node Ubuntu VM cluster with dedicated master and worker roles for distributed computing
  • Configured Hadoop core services, HDFS block replication, and YARN node-manager allocation to process large-scale workloads
  • Implemented distributed data extraction, transformation, and querying workflows for high-volume datasets
